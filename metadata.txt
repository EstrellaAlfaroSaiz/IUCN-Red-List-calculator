about=<p><b>EN:</b> IUCN Red List calculator is a QGIS plugin for preliminary Red List spatial assessment workflows. It downloads GBIF occurrence records with methodological filters, supports manual points and imported point layers, calculates Area of Occupancy (AOO) using a configurable grid and Extent of Occurrence (EOO) using a convex hull, and exports IUCN/SRedList-compatible Point Distribution data as CSV or shapefile. It includes audit tables for records removed by filters and tools to request an official GBIF occurrence download DOI for the GBIF records used. The results are intended to support expert review and do not replace a full IUCN Red List assessment.</p><p><b>ES:</b> IUCN Red List calculator es un complemento de QGIS para apoyar flujos de trabajo espaciales preliminares en evaluaciones de Lista Roja. Descarga registros de presencia de GBIF con filtros metodológicos, permite incorporar puntos propios y capas de puntos importadas, calcula el Área de Ocupación (AOO) mediante una cuadrícula configurable y la Extensión de Presencia (EOO) mediante polígono convexo, y exporta datos Point Distribution compatibles con IUCN/SRedList en CSV o shapefile. Incluye tablas de auditoría de registros eliminados por filtros y herramientas para solicitar a GBIF un DOI oficial de descarga para los registros utilizados. Los resultados sirven como apoyo a la revisión experta y no sustituyen una evaluación formal de Lista Roja IUCN.</p><p><b>Recommended citation / Cita recomendada:</b> Alfaro-Saiz, E. (2026). IUCN Red List calculator v1: QGIS plugin. Sociedad Española de Biología de la Conservación de Plantas (SEBiCoP).</p>
